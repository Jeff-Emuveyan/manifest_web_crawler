This project contains two files that will help you web-crawl a given themanifest.com page and extract out all the company website urls.

The first file is: manifest_web_crawler_by_page_number.py
This program crawls the webpage using the page number you provided.
Before running this file, go to line 11 and edit the url.
Then run the project. It will ask you to provide a page number.
After you have done that it will extract all the website url for that page number.

The first second is: manifest_web_crawler_by_page_range.py
This program crawls all the webpages withing the range that you provided.
Before running this file, go to line 11 and edit the url.
Then run the project. It will ask you to provide a start and end page number.
After you have done that it will extract all the website url withing the page range.
